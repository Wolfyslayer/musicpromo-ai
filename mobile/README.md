# MusicPromo AI — Expo mobile app

Expo SDK 57 + Expo Router + NativeWind, sharing Supabase with the Vite web app in the repo root.

## Setup

```bash
npm install
cp env.example .env
# EXPO_PUBLIC_SUPABASE_URL=
# EXPO_PUBLIC_SUPABASE_ANON_KEY=
npm start
```

See [docs/MOBILE_MIGRATION.md](../docs/MOBILE_MIGRATION.md) for route mapping, web-only libraries, and migration status.
